# TypeMatch Studio

TypeMatch Studio is a local-first typography analysis, comparison, and pairing tool built with React, TypeScript, TanStack Start, Tailwind CSS, and Vite.

## Requirements

- Node.js 22.12 or newer
- npm 10 or newer

## Run locally

```bash
npm ci
npm run dev
```

Vite prints the local URL when the development server is ready.

## Production build

```bash
npm run typecheck
npm run build
npm run start
```

Use `npm run preview` to inspect the production build with Vite instead.

## Quality commands

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```

Formatting, linting, type checking, and the production build should all pass before changes are merged.

## Main folders

```text
src/components/typematch/  Product components
src/components/ui/         shadcn/Radix UI primitives
src/data/                  Typeface catalogue and metadata
src/lib/                   Pairing, comparison, and browser storage logic
src/routes/                TanStack file-based routes
```

`src/routeTree.gen.ts` is generated by TanStack Router. Do not edit it manually.

# Open-source preview fonts

The font files in this directory are used only for catalogue previews.

- VG5000, Terminal Grotesque, Le Murmure, Anthony, Cirrus Cumulus, Trickster,
  PicNic, Ouroboros, Mourier, Steps Mono, Karrik, Format 1452, Sporting
  Grotesque, Lack, Basteleur, Lineal, Avara, Compagnon, and Happy Times are distributed
  by [Velvetyne Type Foundry](https://velvetyne.fr/) under the SIL Open Font
  License 1.1.
- The corresponding license text is included in `licenses/velvetyne-OFL-1.1.txt`.
- Source repositories and current downloads are available from
  [Velvetyne's download catalogue](https://velvetyne.fr/download/).
- Apfel Grotezk, Redaction, Junction, Fanwood Text, Sorts Mill Goudy,
  Orbitron, Ostrich Sans, Goudy Bookletter 1911, Linden Hill, Prociono,
  Sniglet, Knewave, Bagnard, Savate, Libertinus Serif, Libertinus Sans,
  Libertinus Mono, PT Sans, PT Serif, and Quicksand are packaged from the
  [Fontsource](https://fontsource.org/) catalogue. Fontsource records these
  files as SIL Open Font License 1.1.
- Coconat, Absans, Ronzino, Sinistre, and Messapia come from
  [Collletttivo](https://www.collletttivo.it/), whose catalogue releases them
  under the SIL Open Font License 1.1.
- Geist and Geist Mono come from Vercel's official `geist` package. Their
  license is included in `licenses/geist-OFL.txt`.
- Luperca, Canarina, Picaflor, and Piscolabis by Ariel Martín Pérez, Paysage
  by Anton Moglia, and Isenheim by Benoît Ferran are distributed by
  [Tunera Type Foundry](https://www.tunera.xyz/) under the
  SIL Open Font License 1.1. These preview files come from each typeface's
  official Tunera specimen page. The license text is included in
  `licenses/tunera-OFL-1.1.txt`.
- Fontshare previews are declared in `src/styles/fontshare-fonts.css` using
  the official Fontshare API metadata and Fontshare CDN files. No Fontshare
  font binaries are redistributed by this repository.

Do not place commercial or trial font files in this directory unless their
license explicitly permits web embedding and redistribution with this project.
